# metadata-general-audit

Controlla pagina e sito per i motori di ricerca e di risposta AI, applica la bozza dei metadati e implementa i suggerimenti scelti. Parte solo quando la chiami per nome.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Ottimizza il sito per la ricerca e le risposte AI](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/metadata-general-audit). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install metadata-general-audit@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install metadata-general-audit@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/metadata-general-audit` tra le skill dell'agente, per esempio in `~/.codex/skills/metadata-general-audit`.

# coordinate-metadata-saio

Controlla pagina e sito per i motori di ricerca e di risposta AI, applica la bozza dei metadati e implementa i suggerimenti scelti. Parte solo quando la chiami per nome.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Coordinate metadata SAIO](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/coordinate-metadata-saio). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install coordinate-metadata-saio@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install coordinate-metadata-saio@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Con altri agenti copia la cartella `skills/coordinate-metadata-saio` tra le skill dell'agente, per esempio in `~/.codex/skills/coordinate-metadata-saio`.
